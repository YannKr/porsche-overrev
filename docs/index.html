DME over-rev reader

This page reads the over-rev counters of a Porsche engine computer (DME) through an OBDLink adapter. For each of six engine-speed ranges above the rev limit, it shows how many ignitions happened in that range and the engine's operating hours when that range was last reached. It also shows the highest engine speed on record and the stored fault codes.

It only reads. It sends no command that changes anything in the car. Nothing is installed, and the results stay on this computer. It is tested only on a US 991.2 GT3 DME (part number 991.618.692.17, software 3671). For any other DME, it shows a note. This page itself has not yet been tried with a real adapter; the command-line version has.

Before you start

  • Pair the OBDLink in your computer's Bluetooth settings, or plug in a USB OBDLink.
  • Plug the adapter into the car's diagnostic port.
  • Turn the ignition on, with the engine off.
  • Make sure that no phone is connected to the adapter.

Your browser then shows a list of ports. Choose the OBDLink.

    overrev is open source. It works in Chrome or Edge on a computer. Source, command-line version and phone instructions: github.com/YannKr/porsche-overrev
